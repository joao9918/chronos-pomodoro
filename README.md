# 📖 Sobre

O **Chronos** é um temporizador Pomodoro baseado na web que ajuda os usuários a manterem o foco enquanto gerenciam sessões de trabalho ou estudo utilizando a Técnica Pomodoro.

A aplicação oferece uma interface intuitiva com intervalos de trabalho e descanso configuráveis, permitindo que os usuários personalizem seu fluxo de produtividade.

---

# ✨ Funcionalidades

## ⏱ Temporizador Pomodoro

* Temporizador regressivo funcional
* Iniciar, pausar e reiniciar o temporizador
* Alternância automática entre ciclos
* Duração do período de trabalho configurável
* Duração do intervalo curto configurável
* Duração do intervalo longo configurável

# 🚀 Primeiros Passos

Clone o repositório

```bash
git clone https://github.com/joaogabriel-11/chronos-pomodoro.git
```

Acesse a pasta do projeto

```bash
cd chronos-pomodoro
```

Instale as dependências

```bash
npm install
```

Execute localmente

```bash
npm run dev
```
